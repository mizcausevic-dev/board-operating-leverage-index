# Origin

Board Operating Leverage Index exists after the scorecards, trust-room, procurement-answer, RFP assembly, proof-gap, board memo, benchmark, scenario, allocation, priority, reallocation, preservation, takeout, and efficiency-proof layers.

The earlier tools show where to invest, what to freeze, what to cut, and what already landed. This repo turns that stack into one leverage surface so leadership can explain what scales, where drag remains, which owners are ready to expand the gains, and which leverage claims actually survive a board or diligence room.
